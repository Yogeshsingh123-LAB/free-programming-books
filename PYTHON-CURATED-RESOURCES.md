## 1. Priority Tiers

### ✅ TIER 1 — Must Read (Core Python, All Roles)

These are the best free resources for learning Python from scratch to production-quality code.

| Book | Author | Why It's Essential |
|------|--------|--------------------|
| [A Byte of Python](https://python.swaroopch.com) | Swaroop C H | Best first book for absolute beginners. Concise, modern (3.x), and beloved worldwide. |
| [Automate the Boring Stuff with Python (3rd Ed)](https://automatetheboringstuff.com/3e/) | Al Sweigart | Teaches real-world problem solving immediately — the fastest way to see Python's power. |
| [Think Python 3rd Edition](https://greenteapress.com/wp/think-python-3rd-edition/) | Allen B. Downey | Builds CS fundamentals and clean thinking. Excellent for solid understanding. |
| [Python for Everybody](http://py4e.com/book) | Charles R. Severance | Covers everything from syntax to databases and web — very practical and beginner-friendly. |
| [Intermediate Python](https://book.pythontips.com/en/latest/) | Muhammad Yasoob Ullah Khalid | The essential next step after basics — decorators, generators, context managers, etc. |
| [The Hitchhiker's Guide to Python](https://docs.python-guide.org) | Kenneth Reitz et al. | Best practices and idiomatic Python for production. A must before writing any real codebase. |
| [Python 3 Official Documentation](https://docs.python.org/3/download.html) | Python.org | The ground truth. Use it as a constant reference throughout your journey. |

## 2. Recommended Reading Sequence

Follow this sequence for a solid beginner-to-production journey (all roles).

```
Phase 1: Foundation (Weeks 1–6)
───────────────────────────────
 1. A Byte of Python                              ← Start here. Get syntax right.
 2. Automate the Boring Stuff with Python (3rd)  ← Apply Python to real tasks immediately.
 3. Learn Python in Y minutes                    ← Quick reference to fill in gaps.

Phase 2: Thinking Like a Programmer (Weeks 7–12)
─────────────────────────────────────────────────
 4. Think Python 3rd Edition                     ← Build CS fundamentals properly.
 5. Python for Everybody                         ← End-to-end practical tour.
 6. Intermediate Python                          ← Level up with advanced features.

Phase 3: Writing Good Code (Weeks 13–18)
─────────────────────────────────────────
 7. The Hitchhiker's Guide to Python             ← Best practices for real projects.
 8. Google's Python Style Guide                  ← Read once and internalize.
 9. Beyond the Basic Stuff with Python           ← OOP, testing, debugging.
10. The Little Book of Python Anti-Patterns      ← Learn what NOT to do.

Phase 4: Production & Architecture (Weeks 19–26)
──────────────────────────────────────────────────
11. Problem Solving with Algorithms & Data Structures (Python) ← DS&A for interviews & perf.
12. Clean Architectures in Python                ← Structure real projects.
13. Architecture Patterns with Python            ← DDD, events, microservices.
14. Research Software Engineering with Python    ← Testing, packaging, CI/CD.

Phase 5: Specialize (Month 7+)
───────────────────────────────
  → Follow your career path below ↓
```

## 3. Career Learning Paths

### A. Data Analyst Path

**Goal:** Extract insights from data, build dashboards, and communicate findings.

```
Month 1-2: Python Foundation
  → Phase 1 + Phase 2 above (A Byte of Python → Python for Everybody)

Month 3: Data Manipulation
  → Python for Data Analysis (Wes McKinney)             [MUST READ]
  → Best Pandas Tutorial | Learn with 50 Examples       [PRACTICE]
  → pandas: powerful Python data analysis toolkit       [REFERENCE]

Month 4: Statistical Thinking
  → Computational and Inferential Thinking              [MUST READ]
  → Introduction to Python for Econometrics, Statistics [RECOMMENDED]

Month 5: Visualization
  → Scientific Visualization: Python + Matplotlib       [RECOMMENDED]
  → Python Data Science Handbook (Ch. 4 — Visualization)[REFERENCE]

Month 6: End-to-End Project
  → Full Stack Python (understand deployment basics)
  → Build a data pipeline + dashboard project
```
